# AES 表格导入导出规则

## 使用边界

本 Reference 用于产品内列表的批量导入和数据导出。

- 先由列表模板确定业务对象、筛选、选择和总数，再调用本 Reference。
- 本 Reference 只定义入口、流程、状态、结果和异常反馈，不定义具体业务字段、权限模型或后端接口。
- 资产身份信息导入属于独立业务流程，以 MAC 地址匹配资产并更新身份字段，不适用本 Reference。设计或评审其他导入功能时，不得参考其处理方式。

## 导入规则

### 入口与配置

- 将导入作为列表工具栏的全局操作，不要求先选择表格行。
- 按“下载模板 → 上传文件 → 设置冲突规则 → 提交导入”的顺序组织流程。
- 上传前校验文件格式、空文件和文件大小；未上传有效文件时禁用“导入”按钮。
- 当不同冲突策略会产生不同业务结果时，对重复数据提供明确的冲突策略，若需求无特殊说明则用“跳过”和“替换”；默认选择“跳过”。
- 若重复数据采用不同策略的最终结果相同，则不展示策略选项，改为顶部横幅提示重复数据直接跳过。
- 业务字段校验由服务端完成，前端必须承接并展示服务端返回的行号、字段、内容和原因。

### 进行中状态

- 区分文件上传和导入任务两个阶段，分别反馈上传进度和导入进度。
- 提交成功后关闭配置弹窗，进入独立的导入进度状态，展示文件名和进度。
- 防止重复提交和重复轮询。
- 文件过期时清理旧文件状态，并引导用户重新上传。
- 没有任务中心、通知或其他结果恢复入口时，不允许进行中的任务被无反馈关闭；若允许离开，必须提供可恢复的任务入口。

### 结果与异常

- 至少区分全部成功、部分成功和全部失败。
- 部分成功或存在冲突时，展示成功数、失败数、跳过数和异常明细。
- 异常明细至少包含行号、异常类型、异常字段、导入内容和异常描述。
- 服务端返回有效报告文件时，提供“下载异常报告”；没有文件时不显示无效下载入口。
- 导入完成后刷新列表，清空旧选择，并按页面约定重置分页。

## 导出规则

### 范围与确认

- 固定导出范围优先级：已选数据 > 当前筛选结果 > 全部数据。
- 未选择数据但存在筛选条件时，只导出符合当前筛选条件的数据。
- 确认提示必须展示导出范围和数量，不直接静默下载。
- 无数据时禁用导出，并说明不可导出的原因。

### 数量与任务

- 将导出数量上限作为业务配置，不在通用规则中写死具体数值。
- 超过上限时明确提示实际处理方式，例如按顺序导出前 N 条；不得让用户误以为全部数据都会导出。
- 确认后创建异步导出任务并展示进度。
- 任务完成后自动下载文件；任务失败、缺少任务标识、缺少文件标识或下载失败时，提供明确反馈。

## 状态清理

- 流程结束后清理文件、冲突策略、进度、结果和临时选择状态。
- 关闭结果弹窗后不得残留上一次任务的文件名、数量或异常数据。
- 页面卸载或流程切换时停止轮询，避免后台定时器继续更新已失效页面。

## 参考实例

自定义 IOC 可作为普通表格导入导出的参考实例：

- 导入格式为 CSV。
- 文件大小限制为 20 MB。
- 冲突策略为“跳过”和“替换”。
- 导出数量上限为 1 万条。

以上数值只代表该业务当前实现，不作为其他业务的默认值。

## 验收重点

- 验证导入和导出入口在无数据、无选择和有筛选等状态下的可用性。
- 验证文件校验、冲突策略、范围提示、数量限制和进度展示。
- 验证全部成功、部分成功、全部失败、文件过期和任务失败等结果分支。
- 验证异常报告、自动下载、列表刷新和状态清理。
