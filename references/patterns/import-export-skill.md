# AES 表格导入导出规则

## 使用边界

本 Reference 用于产品内列表的批量导入和数据导出。

- 先由列表模板确定业务对象、筛选、选择和总数，再调用本 Reference。
- 本 Reference 只定义入口、流程、状态、结果和异常反馈，不定义具体业务字段、权限模型或后端接口。
- 资产身份信息导入属于独立业务流程，以 MAC 地址匹配资产并更新身份字段，不适用本 Reference。设计或评审其他导入功能时，不得参考其处理方式。

## 导入规则

### 三阶段布局契约

导入前、中、后是三个互斥的任务状态。默认使用同一列表页上的弹窗或遮罩承载，不额外创建顶部 Tab 或独立页面；只有业务明确要求任务中心时，才增加任务恢复入口。

```text
列表页（背景保持可识别，使用遮罩）
        |
        v
+-----------------------------+
| 导入                    [×] |
|                             |
| ① 下载模板                  |
|    说明 / 下载按钮          |
|                             |
| ② 上传文件                  |
|    说明 / 上传按钮 / 文件   |
|                             |
| ③ 导入规则                  |
|    说明 / 策略或固定提示    |
|                             |
|                 [导入] [取消]|
+-----------------------------+
        |
        | 提交成功
        v
+-----------------------------+
| 正在导入              [×]* |
|                             |
| [文件图标] 文件名           |
| 当前处理阶段说明            |
| [==========------] 62%      |
| 已处理 79 / 128             |
| 任务进行中状态提示          |
+-----------------------------+
        |
        | 完成 / 失败
        v
+-----------------------------+     +-----------------------------------+
| 导入                    [×] |     | 批量导入结果                  [×] |
|                             |     | [警告图标] 导入完毕             |
|         [成功图标]          |     | 0 条新增，0 条失败，1 条冲突跳过 |
|          导入成功           |     |                  [下载异常报告] |
| 2 条新增，0 条冲突跳过      |     | 异常信息列表                     |
|                             |     | 行号 | 类型 | 字段 | 内容 | 描述 |
+-----------------------------+     |                                   |
                                      |                         [我知道了] |
                                      +-----------------------------------+
```

`*` 表示关闭能力由任务恢复设计决定；没有恢复入口时应隐藏、禁用或在关闭前明确提示，不得让任务无反馈地丢失。

布局要求：

- 导入配置弹窗负责准备和提交，不展示后台任务进度。
- 导入进度弹窗负责反馈任务，不允许返回修改文件或冲突策略。
- 导入结果弹窗负责解释最终结果，不继续显示处理中进度；结果只使用“完全成功”和“含失败或冲突”两种布局。
- 进度弹窗应比结果弹窗更紧凑；结果弹窗需要为数量摘要和异常表格预留空间。
- 含失败或冲突的结果必须采用“摘要区 + 异常信息列表 + 底部确认操作”的纵向结构，不改为提示横幅、统计卡片或其他信息架构。
- 异常报告下载按钮位于摘要区右侧或同一信息层级，不放在底部操作区；底部只保留“我知道了”或等价的完成操作。
- 异常信息列表固定使用五列：行号、类型、异常字段、导入内容、异常描述；不得因全部失败或全部冲突而删减“类型”列。
- 任务切换时关闭上一阶段的主弹窗，再打开下一阶段，避免多个主弹窗叠加。
- 进行中的任务没有任务中心、通知或其他恢复入口时，不允许用户无反馈关闭、刷新或离开；有恢复入口时可允许关闭，但必须告知任务仍会继续执行以及如何找回结果。

阶段流转：

```text
导入前 --提交成功--> 导入中 --完成/失败--> 导入后
  ^                    |
  |                    +--任务创建失败--> 导入后（失败结果）
  +--上传失败/文件过期-+
```

结果布局分支：

- 完全成功（失败数为 0 且冲突数为 0）：使用简洁成功结果，保留结果弹窗标题、成功图标、“导入成功”标题和数量摘要，只保留关闭入口，不展示异常表格、异常报告入口或额外操作按钮。
- 含失败或冲突（包括部分失败、全部失败、部分冲突和全部冲突）：统一使用异常结果布局，展示成功、失败、跳过/冲突数量、异常明细和可用的异常报告下载；不得为“全部失败”或“全部冲突”另造一套结果页面。
- 只有当“跳过”和“替换”会产生不同业务结果时，配置阶段才展示策略控件；否则在导入规则区域提供固定处理提示，并在结果阶段展示实际跳过数量。

### 入口与配置

- 将导入作为列表工具栏的全局操作，不要求先选择表格行。
- 按“下载模板 → 上传文件 → 设置冲突规则 → 提交导入”的顺序组织流程。
- 上传前校验文件格式、空文件和文件大小；未上传有效文件时禁用“导入”按钮。
- 当不同冲突策略会产生不同业务结果时，对重复数据提供明确的冲突策略，若需求无特殊说明则用“跳过”和“替换”；默认选择“跳过”。
- 若重复数据采用不同策略的最终结果相同，则不展示策略选项，改为顶部横幅提示重复数据直接跳过。
- 业务字段校验由服务端完成，前端必须承接并展示服务端返回的行号、字段、内容和原因。

### 进行中状态

- 区分文件上传和导入任务两个阶段，分别反馈上传进度和导入进度。
- 提交成功后关闭配置弹窗，进入独立的导入进度状态，展示文件名和进度。
- 防止重复提交和重复轮询。
- 文件过期时清理旧文件状态，并引导用户重新上传。
- 没有任务中心、通知或其他结果恢复入口时，不允许进行中的任务被无反馈关闭；若允许离开，必须提供可恢复的任务入口。

### 结果与异常

- 结果固定为两种样式：完全成功，或含失败/冲突的异常结果；不得再按部分失败、全部失败、部分冲突、全部冲突拆分出更多结果样式。
- 只要失败数大于 0 或冲突数大于 0，就使用异常结果样式；即使成功数为 0，也不得降级为简单错误提示。
- 异常结果展示成功数、失败数、跳过/冲突数和异常明细。
- 异常明细至少包含行号、异常类型、异常字段、导入内容和异常描述。
- 服务端返回有效报告文件时，提供“下载异常报告”；没有文件时不显示无效下载入口。
- 导入完成后刷新列表，清空旧选择，并按页面约定重置分页。

## 导出规则

### 范围与确认

- 固定导出范围优先级：已选数据 > 当前筛选结果 > 全部数据。
- 未选择数据但存在筛选条件时，只导出符合当前筛选条件的数据。
- 确认提示必须展示导出范围和数量，不直接静默下载。
- 无数据时禁用导出，并说明不可导出的原因。

### 数量与任务

- 将导出数量上限作为业务配置，不在通用规则中写死具体数值。
- 超过上限时明确提示实际处理方式，例如按顺序导出前 N 条；不得让用户误以为全部数据都会导出。
- 确认后创建异步导出任务并展示进度。
- 任务完成后自动下载文件；任务失败、缺少任务标识、缺少文件标识或下载失败时，提供明确反馈。

## 状态清理

- 流程结束后清理文件、冲突策略、进度、结果和临时选择状态。
- 关闭结果弹窗后不得残留上一次任务的文件名、数量或异常数据。
- 页面卸载或流程切换时停止轮询，避免后台定时器继续更新已失效页面。

## 参考页面

主要参考页面：

- 自定义 IOC / 文件 Hash
- 路由：`/aes/policy/ioc-policy/hash`
- 同类页面：
  - `/aes/policy/ioc-policy/ip`
  - `/aes/policy/ioc-policy/domain`


自定义 IOC 可作为普通表格导入导出的参考实例：

- 导入格式为 CSV。
- 文件大小限制为 20 MB。
- 冲突策略为“跳过”和“替换”。
- 导出数量上限为 1 万条。

若无特殊说明，则默认用以上数值只作为其他业务的默认值。


## 验收重点

- 验证导入和导出入口在无数据、无选择和有筛选等状态下的可用性。
- 验证导入前配置、导入中进度、导入后结果三个状态按顺序切换，且不会同时叠加多个主弹窗。
- 验证三个状态的布局重点分别是配置、任务进度和结果解释；不得用单一上传弹窗替代完整流程。
- 验证文件校验、冲突策略、范围提示、数量限制和进度展示。
- 验证完全成功，以及含失败或冲突的统一异常结果（包括全部失败和全部冲突）、文件过期和任务失败等结果分支。
- 验证异常报告、自动下载、列表刷新和状态清理。
