# AES 表格导出规则

## 使用边界

本 Reference 用于产品内列表的数据导出。

- 先由列表模板确定业务对象、筛选、选择和总数，再调用本 Reference。
- 本 Reference 只定义导出入口、范围、确认、状态和异常反馈，不定义具体业务字段、权限模型或后端接口。
- 导出范围和数量应以当前列表实际可见的数据上下文为准。

## 入口与范围

- 将导出作为列表工具栏的全局操作。
- 固定导出范围优先级：已选数据 > 当前筛选结果 > 全部数据。
- 未选择数据但存在筛选条件时，只导出符合当前筛选条件的数据。
- 确认提示必须展示导出范围和数量，不直接静默下载。
- 无数据时禁用导出，并说明不可导出的原因。

范围确认示例：

```text
导出数据

导出范围：当前筛选结果
数据数量：826 条

                         [导出] [取消]
```

## 数量与任务

- 将导出数量上限作为业务配置，不在通用规则中写死具体数值。
- 超过上限时明确提示实际处理方式，例如按当前排序顺序导出前 N 条；不得让用户误以为全部数据都会导出。
- 确认后创建异步导出任务并展示进度。
- 任务完成后自动下载文件。
- 任务失败、缺少任务标识、缺少文件标识或下载失败时，提供明确反馈。

## 进行中状态

导出确认和导出进度是两个互斥状态。确认后关闭确认弹窗，再打开进度弹窗，避免多个主弹窗叠加。

```text
导出确认 --确认--> 导出进行中 --完成--> 自动下载
                      |
                      +--失败--> 失败结果
```

没有任务中心、通知或其他恢复入口时：

- 进行中的任务不允许无反馈关闭、刷新或离开。
- 进度弹窗展示导出范围、数量、文件名和当前进度。
- 防止重复提交和重复查询。
- 页面卸载或流程切换时停止查询，避免后台定时器继续更新已失效页面。

## 完成与异常

导出成功后：

- 自动下载文件。
- 反馈文件已生成或已开始下载。
- 关闭进度状态并清理任务数据。

导出失败时展示统一失败结果：

```text
导出失败

未能生成导出文件，请重新尝试。

                         [重新导出] [关闭]
```

不得把缺少任务标识、缺少文件标识和下载失败表现为无响应或静默结束。

## 状态清理

- 流程结束后清理导出范围、数量、文件名、进度和临时选择状态。
- 关闭失败结果后不得残留上一次任务的文件名、数量或进度。
- 新建导出任务前停止上一次未结束的查询，防止重复轮询。

## 验收重点

- 验证已选数据、当前筛选结果和全部数据三种范围的优先级。
- 验证确认提示展示范围和数量，且无数据时导出不可用。
- 验证数量上限提示不会造成“全部数据都会导出”的误解。
- 验证导出确认、导出进度、自动下载和失败结果按顺序切换。
- 验证任务失败、缺少任务标识、缺少文件标识、下载失败和状态清理。
