# AES 产品背景

## 产品定位

AES 是深信服下一代端点安全产品，围绕终端安全防护、检测、调查、响应、策略配置、任务执行和客户端管理提供能力。

使用本文件建立需求理解所需的产品边界。具体业务对象、治理模型和页面规则由命中的主题 Reference 定义。

## 设计原则

- 先识别管理对象、用户任务、治理模型和生效链路，再判断主题归属。
- 优先复用 AES 已有业务对象和能力链路；只有业务对象或治理模型不同才建立新主题或模块。
- 真实产品页面、接口和项目代码是 AES 差异规则的重要证据；只继承明确命中的能力，不整页照搬。
- 公共设计规则是默认基线；AES 同层 Reference 只表达产品差异和专属约束。
- AES 未定义的业务事实不得由页面样式、术语或公共模板反推。

## 主题边界基线

- 规则：以匹配条件和命中结果管理独立规则实例。
- 策略：以配置、优先级、分配、生效与生命周期管理策略实例或安全策略配置。
- 任务：以执行目标、执行过程、状态与结果管理一次性或周期执行。
- 病毒防护：以病毒检测对象、检测记录、风险判断和处置闭环组织能力。

主题边界以具体 Reference 和真实证据为准；上述内容只用于初步候选，不替代主题建模。
