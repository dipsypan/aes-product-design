# AES 资产卡片复用规则

> `Coverage: override`
> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属组件映射，不作为 Common Design 的通用组件规范。本组件能力整体采用 AES `override`，本文定义的规则直接以 AES 为准；未登记的其他组件能力才由 `prd-design-code` 调用 Common Design 或依据项目已有代码处理。

## 使用条件

- 页面展示单台具体资产摘要。
- 当前容器没有完整资产信息区域。
- 悬停展示不会与行点击、详情抽屉或其它外层操作冲突。

## 不适用与禁止事项

- 当前页面或抽屉已经完整展示该资产信息时，不再嵌套资产卡片。
- 资产对象含义无法确认，或不是单台具体资产时，不调用该组件。

## Component 身份

- `componentId: AssetCard`
- `encapsulation: true`
- 组件能力：单台资产摘要卡片

## 能力边界

- 组件提供：资产字段、内容顺序、视觉样式、尺寸和卡片内部交互，沿用项目已有 `AssetCard`。
- 业务提供：当前信息是否指向单台具体资产，以及外层点击、详情和抽屉交互关系。
- 单台资产摘要且当前容器没有完整资产信息区时，默认通过悬停复用资产卡片；已有完整信息区时不重复使用。
- 资产卡片不重新决定 Theme、页面容器或详情结构；封装不足时按本文件的对象判断与外层交互规则补充。

## 3. 已有参考场景

以下场景用于说明已有资产卡片的复用基线。它们是参考证据，不是限定只能使用资产卡片的页面白名单。只记录页面位置、业务字段和实现参考，不复制资产卡片内容。

| 业务场景 | 页面字段或区域 |
| --- | --- |
| 病毒列表 | 表格中的“影响资产” |
| 安全事件列表 | 表格中的“影响资产” |
| 告警链列表 | 表格中的“影响资产” |
| 日志调查列表 | 表格中的“影响资产” |
| 文件隔离区 | 表格中的资产信息或生效资产 |
| 任务记录 | 表格中的“影响资产” |

新增页面遇到单台资产摘要时，沿用同一规则直接复用已有资产卡片，不需要在方案中重新声明组件，也不另起一套资产信息浮层。

## 额外例外

- 当前页面或抽屉已经完整展示该资产信息时，不再在资产名称、IP 或其他字段上嵌套资产卡片。
- 病毒详情抽屉等已经存在完整资产信息区域的页面，遵循页面已有的信息组织，不重复触发资产卡片。
- 资产详情页本身不再通过资产卡片重复展示当前资产。
- 资产信息含义无法确认是否对应单台具体资产时，本 Reference 不替代业务语义判断；应返回上层确认资产对象，再决定是否复用资产卡片。

完整资产信息例外优先于“出现资产信息即复用资产卡片”的默认规则。

## 5. 交互边界

- 资产摘要悬停时展示已有资产卡片；离开触发区域后按现有组件行为关闭。
- 资产卡片所在的列表单元格或信息区域不得误触发行详情、打开外层抽屉或触发其他外层操作。
- 卡片内部的关闭、详情跳转、字段展开和复制等行为沿用已有 `AssetCard` 实现，不在本 Reference 中重新定义。

## 6. 判断流程

```text
页面出现资产相关信息
├── 当前是否已经有完整资产信息区域？
│   ├── 是 → 不再使用资产卡片
│   └── 否
│       ├── 是否为单台具体资产摘要？
│       │   ├── 是 → 悬停复用已有资产卡片
│       │   └── 否或含义不明确 → 本 Reference 不替代上层业务判断
```

## 7. 复用检查

- 设计遇到与真实参考场景同类的单台资产信息时，能够自动判断复用资产卡片。
- 资产卡片默认通过悬停触发。
- 已经完整展示资产信息的页面没有重复嵌套资产卡片。
- 资产卡片没有改变列表行点击、详情抽屉或其他外层交互语义。
- 本 Reference 没有重新定义资产卡片的字段、内容结构、尺寸或样式。
- 参考场景仅作为复用证据，不限制单台资产在新页面继续复用已有资产卡片。
- 资产对象含义不明确时，没有凭本 Reference 虚构资产卡片适用范围。
