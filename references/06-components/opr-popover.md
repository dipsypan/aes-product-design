# AES 悬停操作卡片

> `Coverage: override`
> **归属：AES Product Design。** 本 Reference 是 AES 已封装的悬停操作卡片组件规范，不作为 Common Design 的通用组件规范。

## 使用条件

- 字段或表格内容需要承载与当前值相关的快捷操作；
- 用户悬停后需要查看完整字段值并直接执行操作；
- 前端使用已封装的 `OprPopover`。

## Component 身份

- `componentId: OprPopover`
- 中文名：悬停操作卡片
- `encapsulation: true`
- 来源：AES 前端已有封装

## 结构

卡片固定由两层组成：

1. 上层：完整字段值；
2. 分割线；
3. 下层：操作按钮。

## 场景一：实体字段操作

用于详情页面中实体相关的可执行操作字段，例如文件路径、进程文件路径、SHA256、MD5、实体名称。支持复制、下发处置、恢复、调查和添加规则等操作。

操作按钮规则：

- 默认第一个为复制；
- 业务操作入口最多外放 3 个；
- 业务操作不超过 3 个时全部并排展示；
- 超过 3 个时默认外放前 2 个，其余收进 `ellipsis` 下拉菜单。
- `ellipsis` 下拉菜单面板遵循 [`dropdown.md`](dropdown.md) 的分组横线规范。

未特殊定义时，业务操作按以下顺序排列：

1. 处置：删除、禁用等；
2. 解除处置：恢复、解除禁用等；
3. 添加规则：添加白名单规则、添加黑名单规则；
4. 调查：文件名、文件路径、Hash、情报调查等。

## 场景二：表格条件操作

一般用于表格高级检索场景，操作按钮按以下顺序排列：

1. 添加到条件；
2. 从条件排除；
3. 用此条件发起新的调查，仅日志调查列表显示；
4. 复制。

## 样式与跳转

- 操作按钮默认使用黑色文字，悬停时变为蓝色；
- 需要新页签打开的操作，在按钮后显示跳转图标；
- 当前页面打开弹窗或抽屉的操作不显示跳转图标；
- 处置、解除处置、添加规则通常在当前页面打开下发处置任务弹窗，不显示跳转图标；
- 仅新页签跳转操作显示跳转图标。

## 约束

- 卡片展示完整字段值，不以截断值替代；
- 操作入口的权限、可用状态、确认方式和业务结果由上游规则决定；
- 不在业务页面重复实现 `OprPopover` 已封装的卡片结构和操作按钮布局。
