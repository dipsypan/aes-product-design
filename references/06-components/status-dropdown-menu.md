# AES 启禁用状态下拉组件

> `Coverage: override`
> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属组件映射，不作为 Common Design 的通用组件规范。本组件能力整体采用 AES `override`；本文定义的规则直接以 AES 为准，未登记的其他组件能力才由 `prd-design-code` 调用 Common Design 或依据项目已有代码处理。

## 使用条件

- 业务对象已经存在，当前入口允许独立、即时修改对象的「启用 / 禁用」状态。
- 上游已完成启禁用场景决策，并输出 `single-object-enable-disable-selector` 能力要求。
- 状态值、允许到达的目标状态、权限和切换后果已经由需求、Theme、接口或真实页面确定。

## 不适用与禁止事项

- 新增或编辑表单中的启用状态不使用本组件，使用「启用 / 禁用」Radio 并随表单保存。
- 只读状态不展示可交互下拉箭头，不得伪装成可操作入口。
- 表格批量启用或禁用使用工具栏操作，不使用本组件代替批量动作。
- 不使用本组件反推业务状态集合、默认值、权限、确认方式或请求接口。
- 不在业务页面自行拼装相同的图标、颜色、文案和下拉入口。

## Component 身份

- `componentId: StatusDropDownMenu`
- `encapsulation: true`
- 组件能力：已有业务对象的单条启禁用状态展示与目标状态选择入口
- 来源：AES 前端已有业务封装

本 Component 可以读取 [`../04-patterns/enable-disable.md`](../04-patterns/enable-disable.md) 的语义契约判断是否命中；`enable-disable` Pattern 不反向读取或依赖本文件。

## 复用契约

- 启禁用的图标、颜色、文案、下拉箭头、展开状态和基础菜单样式沿用项目现有 `StatusDropDownMenu`，本文件不重新定义视觉参数。
- 完整的「状态图标 + 状态文案 + 下拉箭头」区域为同一点击目标。
- 当前状态在菜单中保持选中；可选目标状态由上游业务契约传入或按组件真实能力配置。
- 再次选择当前状态不得触发确认、请求或结果反馈。
- 不可操作时保留当前状态图标和文案，入口不可展开；禁用原因由上层交互承载。
- 选择不同状态后的资格判断、二次确认、提交、失败处理和状态回写执行 [`../04-patterns/enable-disable.md`](../04-patterns/enable-disable.md)，不由组件自行决定。

## 实现核验

- 编码前必须核验目标分支中的真实导出名、引用路径、Props、Events、状态值映射和禁用能力。
- 未核验前只能声明设计上要求复用 `StatusDropDownMenu`，不得编造组件 API 或声称已完成代码复用。
- 如果真实组件不能执行上游锁定的状态值、权限或交互契约，返回产生该结论的 Pattern 或 Theme，不得在 Component 层静默更换方案。

## 复用检查

- 只在已有对象的单条即时启禁用场景使用。
- 表单、只读和批量场景没有错误调用本组件。
- 页面没有重新实现组件已经封装的状态视觉和下拉入口。
- 当前状态重复选择不触发业务操作。
- 业务规则、确认和请求流程仍由上游契约控制。
- 已在目标代码分支核验真实组件入口和能力，没有猜测 Props 或 Events。
