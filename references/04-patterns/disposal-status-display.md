# AES 处置状态展示 Pattern

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Pattern，不作为 Common Design 的通用交互规范。本文明确规定的 AES 方案优先；未覆盖事项由 `prd-design-code` 按 Coverage 调用 Common Design 补充。

## 1. 调用条件

当平台支持对某个实体下发处置操作时，必须回显该实体的处置状态。

适用场景包括但不限于：

- 安全事件、告警链中的实体列表
- GPT 研判结果中的可疑实体列表
- 进程图、攻击阶段图的图上实体
- 实体悬浮卡片和实体详情
- 日志详情中的源实体、目标实体
- 文件、进程、IP、域名等支持处置操作的实体

处置状态使用 AES 现有状态文案和标签样式，不自行新增状态名称或颜色。

## 2. 显示方式判断

根据当前页面是否存在独立的“处置状态”语义字段，选择显示位置。

### 2.1 有独立处置状态字段

当列表或详情中已经存在“处置状态”字段、列或属性时：

- 处置状态直接显示在该字段中。
- 不再追加到实体名称后。
- 同一实体的处置状态不得重复显示。

示例：

```text
实体名称：malware.exe
处置状态：已结束
```

### 2.2 没有独立处置状态字段

当页面没有单独的“处置状态”字段，且不应通过固定字段强化处置引导时：

- 将处置状态标签紧跟在对应实体名称后。
- 标签与实体名称保持同一行展示。
- 实体名称过长时，实体名称按页面规则省略，标签仍需完整展示。
- 标签不得放在无关字段、操作列或页面顶部。
- 没有处置状态时不显示空标签。

示例：

```text
malware.exe  [已隔离]
```

适用场景包括可疑实体列表、GPT 研判实体卡片、图上实体、实体详情和日志详情中的实体信息。

## 3. 标签展示规则

- 标签必须紧跟实体名称、目标名称或实体标题。
- 使用 AES 现有处置状态标签组件和状态映射。
- 标签文案统一复用平台状态文案，例如“已结束”“已隔离”“已拦截”。
- 标签和实体名称之间保留平台标准间距。
- 标签不得覆盖、挤压或替代实体名称。
- 实体名称支持省略和 Tooltip，标签不应被省略。
- 同一实体在同一区域只显示一个处置状态标签。

推荐结构：

```text
实体名称 + 处置状态标签 + 其他实体标识
```

禁止结构：

```text
实体名称 + 独立处置状态字段 + 处置状态标签
实体名称 + 处置状态放在操作按钮旁
```

## 4. 状态同步规则

- 处置操作完成后，应更新当前实体的处置状态。
- 同一实体同时出现在列表、图、卡片和详情中时，各区域状态应保持一致。
- 处置操作执行中或结果未返回时，不得伪造最终状态。
- 状态为空或接口未返回时，不显示处置状态标签。
- 状态文案、颜色和图标必须复用 AES 现有状态映射。

## 5. 示例

### 示例一：有独立字段

```text
| 实体名称 | 处置状态 |
| malware.exe | 已结束 |
```

实体名称后不再追加“已结束”标签。

### 示例二：没有独立字段

```text
malware.exe  [已隔离]
```

处置状态跟随实体名称显示，不额外增加“处置状态”字段。

### 示例三：日志详情

```text
源实体：powershell.exe [已结束]
目标实体：malware.exe [已隔离]
```

只有实际支持处置且已有状态的实体显示标签。

## 6. 业务要求

- 支持处置操作的实体能够回显处置状态。
- 有独立处置状态字段时，状态显示在字段中。
- 无独立字段时，状态标签紧跟实体名称。
- 同一实体没有重复显示处置状态。
- 状态为空时不显示空标签。
- 处置完成后，列表、图、卡片和详情中的状态保持一致。
- 使用 AES 现有状态文案、颜色、图标和标签组件。
