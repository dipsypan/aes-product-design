# AES ATT&CK 战术技术展示 Pattern

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Pattern，不作为 Common Design 的通用交互规范。
> `Coverage: extend`
> 本文明确规定的 AES 方案优先；未覆盖事项由 `prd-design-code` 按 Coverage 调用 Common Design 补充。

## 1. 组件定义

用于展示安全事件、告警等对象命中的 ATT&CK 战术与技术，支持聚合统计、多项展开和技术详情外链跳转。

### 1.1 统计规则

- 同一战术重复命中时，只统计 1 个战术。
- 同一技术重复命中时，只统计 1 个技术。
- 同一技术属于多个战术时，技术只统计 1 次，但保留各战术下的对应关系。
- 摘要数量使用去重后的唯一战术数和唯一技术数。
- 无有效数据时显示 `-`。

## 2. 展示模式选择

| 表格形态 | 默认模式 | 展示结构 |
| --- | --- | --- |
| 多行列表型表格 | 合并显示 | 战术和技术共用一个单元格，采用上下布局 |
| 单行详情型表格 | 分开显示 | 战术和技术分别使用独立字段或独立列 |

- 多行列表型表格是指同时展示多条业务数据的列表，例如安全事件列表、告警列表。
- 单行详情型表格是指主要展示一条对象完整信息的表格，例如事件详情、告警详情或对象信息表。
- 以上为默认选择。业务有明确布局要求时可以调整，但必须保证战术与技术的对应关系清晰。

## 3. 外链图标规则

文档中的 `↗` 只表示外链图标，实际页面必须使用项目现有图标库，不得直接输出 `↗` 字符。

仅在以下位置显示外链图标：

- 可直接跳转的单个技术项后。
- 展开明细中的每个技术项后。
- 分开显示模式中的可点击技术项后。

以下位置不显示外链图标：

- 战术名称后。
- “等 N 项”摘要后。
- 用于展开明细的单元格或摘要后。
- 空值 `-` 后。
- 不支持跳转的技术项后。

示意：

```text
战术：Initial Access（TA0001）       不显示外链图标
技术：Phishing（T1566）↗            显示外链图标
技术：Phishing 等 4 项              不显示外链图标
```

技术文字、技术编号和外链图标共同组成一个点击区域。

## 4. 合并显示

合并显示主要用于多行列表型表格。战术在上，技术在下，统一左对齐。

### 4.1 单战术、单技术

默认展示：

```text
┌─────────────────────────────────┐
│ 战术：Initial Access（TA0001）   │
│ 技术：Phishing（T1566）↗         │
└─────────────────────────────────┘
```

- 战术只展示，不跳转。
- 技术项点击后打开 MITRE ATT&CK 官网。
- 悬浮技术项时提示：`点击跳转到 MITRE ATT&CK 官网查看详细介绍`。

### 4.2 多战术、多技术折叠态

默认展示去重后的首项和数量摘要：

```text
┌─────────────────────────────────┐
│ 战术：Initial Access 等 3 项     │
│ 技术：Phishing 等 4 项           │
└─────────────────────────────────┘
```

- 摘要行不显示外链图标。
- 点击单元格摘要打开完整明细。
- 战术数量和技术数量分别统计。

### 4.3 多项展开态

点击摘要后展示按战术分组的明细浮层：

```text
┌──────────────────────────────────────────────┐
│ ATT&CK 战术              ATT&CK 技术          │
├──────────────────────────────────────────────┤
│ Initial Access           Phishing（T1566）↗   │
│ （TA0001）               Exploit Public-      │
│                          Facing App（T1190）↗  │
├──────────────────────────────────────────────┤
│ Execution                PowerShell           │
│ （TA0002）               （T1059.001）↗        │
└──────────────────────────────────────────────┘
```

- 每个技术项后都显示外链图标。
- 点击技术项只执行官网跳转。
- 点击浮层外部区域收起。
- 内容超出最大高度时，在浮层内部滚动。

### 4.4 单技术、多战术

折叠态示意：

```text
┌─────────────────────────────────┐
│ 战术：Initial Access 等 2 项     │
│ 技术：PowerShell（T1059.001）↗   │
└─────────────────────────────────┘
```

展开态示意：

```text
┌──────────────────────────────────────────────┐
│ Initial Access（TA0001）  PowerShell          │
│                          （T1059.001）↗        │
├──────────────────────────────────────────────┤
│ Execution（TA0002）       PowerShell          │
│                          （T1059.001）↗        │
└──────────────────────────────────────────────┘
```

- 技术总数为 1，战术总数为 2。
- 不得只展示第一条战术。
- 同一技术可以在不同战术分组中重复展示关系。

## 5. 分开显示

分开显示主要用于单行详情型表格、详情页或抽屉。

### 5.1 单战术、单技术

```text
┌─────────────────────────┬─────────────────────────┐
│ ATT&CK 战术             │ ATT&CK 技术             │
├─────────────────────────┼─────────────────────────┤
│ Initial Access          │ Phishing（T1566）↗      │
│ （TA0001）              │                         │
└─────────────────────────┴─────────────────────────┘
```

- 战术列不显示外链图标。
- 技术列显示外链图标并支持跳转。

### 5.2 多战术、多技术

空间足够时直接展示：

```text
┌─────────────────────────┬────────────────────────────┐
│ ATT&CK 战术             │ ATT&CK 技术                │
├─────────────────────────┼────────────────────────────┤
│ Initial Access          │ Phishing（T1566）↗         │
│ （TA0001）              │ Exploit Public-Facing      │
│                         │ App（T1190）↗               │
├─────────────────────────┼────────────────────────────┤
│ Execution（TA0002）     │ PowerShell（T1059.001）↗   │
└─────────────────────────┴────────────────────────────┘
```

空间不足时使用摘要：

```text
┌─────────────────────────┬─────────────────────────┐
│ ATT&CK 战术             │ ATT&CK 技术             │
├─────────────────────────┼─────────────────────────┤
│ Initial Access 等 3 项  │ Phishing 等 4 项        │
└─────────────────────────┴─────────────────────────┘
```

- 摘要不显示外链图标。
- 点击摘要后展开完整的战术技术关系明细。
- 展开明细中的技术项显示外链图标。

## 6. 其他状态示意

### 6.1 无数据

合并显示：

```text
┌─────────────────────────┐
│ -                       │
└─────────────────────────┘
```

分开显示：

```text
┌─────────────────────────┬─────────────────────────┐
│ ATT&CK 战术             │ ATT&CK 技术             │
├─────────────────────────┼─────────────────────────┤
│ -                       │ -                       │
└─────────────────────────┴─────────────────────────┘
```

### 6.2 内容过长

```text
技术：Command and Scripting Inter... ↗
```

- 名称过长时单行省略。
- 外链图标保持可见，不随文字一起被截断。
- 悬浮文字时显示完整名称、编号和跳转提示。

## 7. 实现约束

- 合并模式使用同一个表格单元格完成上下布局。
- 多项明细使用项目统一的浮层能力；具体组件入口由 Component 层核验，未封装时使用等价浮层实现。
- 技术外链在新标签页打开，并使用 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 摘要数量必须在展示前完成去重计算。
- 技术链接点击不得触发行点击、浮层切换或其他表格操作。
- 外链图标使用项目图标库，`↗` 不作为页面实际字符输出。
