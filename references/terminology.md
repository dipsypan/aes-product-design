# AES 术语与页面文案 Reference

## 使用边界

只在业务语义、页面框架、操作含义已经确定，需要生成或检查用户可见文案时读取本文件。

- 负责统一 AES 的中英文术语、页面名称、字段名称、按钮、状态、提示和技术内容表达。
- 不参与需求理解、主题分类、容器选型、页面布局和组件选择。
- 不得通过统一文案新增字段、操作、状态或业务规则。
- 原始语义不明确时返回原设计阶段确认，不得自行选择一个术语掩盖歧义。
