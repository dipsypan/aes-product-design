# AES 术语与页面文案规范

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属文案与术语设计规范，不作为 Common Design 的通用规范；它以 `extend` 关系补充 AES 专属词语和表达差异。
> 未在本文定义的内容，按 [Common Design 产品文案与术语规范](../../common-design/references/04-patterns/06-copywriting-terminology.md) 执行。

## 使用边界

只在业务语义、页面框架、操作含义已经确定，需要生成或检查 AES 用户可见文案时读取本文件。

- 负责统一 AES 的专属中英文术语、页面名称、字段名称、按钮、状态和技术实体表达。
- 不参与需求理解、主题分类、容器选型、页面布局和组件选择。
- 不得通过统一文案新增字段、操作、状态或业务规则。
- 原始语义不明确时返回上游确认，不得自行选择术语掩盖歧义。

## 实体与属性表达

### 资产与客户端

两者按对象语义区分，不得混用：

| 推荐词语 | 使用说明 | 不推荐混用 |
| --- | --- | --- |
| 资产 | AES 中可被识别、管理、统计或保护的业务对象 | 已明确指向客户端时，不泛化为资产 |
| 客户端 | AES 部署的客户端程序，或明确表示与 MGR 通信的客户端侧 | 不与资产无条件互换 |


### 网络对象

| 推荐词语 | 不推荐 | 使用说明 |
| --- | --- | --- |
| IP地址 | IP | 表示网络地址实体时使用完整表达。 |
| 域名 | 域名地址 | 域名不是“域名地址”，统一使用“域名”。 |

### 字段与标识

#### Hash 与摘要值

| 场景 | 推荐表达 | 不推荐表达 |
| --- | --- | --- |
| 通用 Hash 术语 | Hash | hash |
| MD5 摘要值 | MD5 | md5、Md5 |
| 进程文件的 MD5 | 进程文件MD5 | 进程 MD5、进程文件 md5 |
| 文件的 MD5 | 文件MD5 | 文件 md5 |
| SHA256 摘要值 | SHA256 | sha256、Sha256 |
| 进程文件的 SHA256 | 进程文件SHA256 | 进程 SHA256、进程文件 sha256 |
| 文件的 SHA256 | 文件SHA256 | 文件 sha256 |

#### 标识符

| 语义 | 推荐表达 | 不推荐表达 |
| --- | --- | --- |
| 进程标识符 | PID | pid |

## 策略与规则用法

| 场景 | 推荐命名 | 用法定义 |
| --- | --- | --- |
| 多层结构，策略引用下层配置 | 策略 + 规则 | 策略负责组织和引用规则；规则负责具体匹配、生效范围和处置配置。 |
| 单层结构，存在优先级匹配 | 策略 | 优先级用于决定多个配置的匹配或生效顺序。 |
| 单层结构，不存在优先级匹配 | 规则 | 每条记录独立完成匹配和处置，不需要策略层协调。 |

规则和策略都可以包含生效范围及安全管控配置。规则负责判断和命中，策略负责管控和生效。

## 客户端检测内容

规则库是安装在资产客户端上的检测规则内容，不是平台上的规则集合，也不作为策略的下级对象。

| 推荐词语 | 不推荐 | 使用说明 |
| --- | --- | --- |
| 规则库 | 病毒库 | 客户端检测内容的统称。 |
| 病毒规则库 | 病毒库 | 客户端用于病毒检测的规则库。 |
| 高级威胁规则库 | 高级威胁库 | 客户端用于高级威胁检测的规则库。 |
| 规则库版本 | 病毒库版本 | 客户端当前安装的规则库版本。 |

## 状态表达

状态值只描述实体当前所处的状态，不带动作对象名词。对象名词由字段、列标题或上下文提供。例如“隔离文件”操作成功后，文件的状态写作“已隔离”，不写作“已隔离文件”。

| 成功动作 | 实体状态 | 不推荐作为状态 |
| --- | --- | --- | --- |
| 隔离文件 | 已隔离 | 已隔离文件、隔离成功 |
| 结束进程 | 已结束 | 已结束进程、结束成功 |
| 清理驻留项 | 已清理 | 已清理驻留项、清理成功 |
| 恢复文件 | 已恢复 | 已恢复文件、恢复成功 |
| 拦截外联 | 已拦截 | 已拦截外联、拦截成功 |
| 限制文件写入 | 已限制 | 已限制文件写入、限制成功 |
| 还原文件 | 已还原 | 已还原文件、还原成功 |

具体处置动作以病毒防护和处置规则中已定义的动作集合为准，不因状态文案规则新增动作。

### Toast 或即时操作反馈

Toast 反馈的是用户刚发起的一次操作，而不是实体当前状态，可以使用“动作 + 成功”：

| 反馈场景 | 推荐表达 | 对应实体状态 |
| --- | --- | --- |
| 处置任务提交或执行完成 | 处置成功 | 已处置，或具体动作状态 |
| 隔离操作完成 | 隔离成功 | 已隔离 |

Toast 表达操作是否成功；状态表达操作完成后实体处于什么状态。页面同时需要反馈两者时，分别使用 Toast 和状态字段，不互相替代。

## 按钮与操作命名

本节只校准按钮、下拉操作组和新标签页入口文案，不决定按钮位置、样式、权限、确认方式或执行结果。

### 动作按钮

- 使用“动作 + 对象”，例如“隔离资产”“结束进程”“禁用客户端”。
- 同一对象的配对动作在上下文清楚时可以省略对象，例如“隔离资产 / 解除隔离”。
- “批量”表示已选对象范围，不写入单个动作按钮；使用“删除”“启用”“禁用”，不使用“批量删除”“批量启用”“批量禁用”。

### 操作组与菜单

- 分组入口只命名操作族或业务范围，例如“资产隔离”“批量操作”“客户端管理”“处置”，不罗列全部子动作。
- 菜单项保持具体动作名。
- 同一菜单中的跳转项排在动作项之后，必要时用分割线区隔。
- 不使用只描述容器而没有业务含义的“更多操作”。

### 新标签页入口

- 文案不增加“打开”“前往”“进入”等冗余前缀。
- 跳转图标和具体实现执行 `05-features/link-navigation.md`；文案中不得把示意字符 `↗` 当作正文输出。

## AI 词语选择规则

1. 先读取本文判断是否存在 AES 专属表达；命中时使用 AES 统一表达。
2. 未命中本文时，使用 Common Design 规范。
3. `Hash`、`MD5`、`SHA256` 和 `PID` 必须保持本文规定的大小写。
4. 根据对象准确使用“进程文件MD5”“文件MD5”“进程文件SHA256”或“文件SHA256”。
5. 使用“IP地址”和“域名”，不得使用“IP”或“域名地址”。
6. 客户端检测内容使用“规则库”，不得将其泛称为“病毒库”。
7. 不得混用“资产”和“客户端”。
8. 多层结构中，策略引用下层配置时使用“策略 + 规则”；单层结构中存在优先级匹配时使用“策略”，不存在优先级匹配时使用“规则”。规则和策略都可以包含生效范围及安全管控配置。
9. 状态、处置结果和记录回显中的成功动作统一使用“已 + 动作”，例如“已隔离”“已结束”“已清理”。
10. Toast 等一次性操作反馈使用“动作 + 成功”，例如“处置成功”；不得将其作为实体状态名称。
11. 动作按钮使用“动作 + 对象”；批量范围不写入单个动作按钮，跳转图标不作为按钮正文字符。
12. 术语边界未确认时，不自行创造统一表达，写入 `unresolved_terms`。
