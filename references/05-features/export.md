# AES 数据导出 Feature

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Feature，不作为 Common Design 的通用能力规范。数据导出在 Coverage 中为 `override`：本文作为当前能力的唯一设计来源，缺失的 AES 导出规则进入 `reference_gaps`，不得自动回退 Common Design。

## 使用边界

本 Feature 在页面方案已确定提供导出能力后读取，完整执行“确定范围 → 确认 → 创建任务 → 下载结果”。它不判断页面是否应该提供导出，也不改变筛选和表格方案。

## 执行流程

```text
点击导出
→ 确定范围和数量
→ 用户确认
→ 创建异步任务并展示进度
→ 完成后下载 / 失败反馈
```

## 范围与确认

- 固定范围优先级：已选数据 > 当前筛选结果 > 全部数据。
- 未选择但存在筛选条件时，导出筛选结果的全部数据，不只导出当前页。
- 未选择且无筛选条件时，导出全部数据。
- 无数据时禁用导出并说明原因。
- 确认内容必须展示实际导出范围和数量，不得静默下载。

## 数量、任务与结果

- 导出数量上限来自业务配置，不在 Feature 中写死。
- 超过上限时明确实际处理方式，例如按顺序导出前 N 条。
- 确认后创建异步任务并展示进度，防止重复提交。
- 任务完成后自动下载；任务失败、任务标识缺失、文件标识缺失或下载失败时明确反馈。
- 流程结束后清理进度和临时状态；页面卸载时停止轮询。

## AES 参考基线

自定义 IOC 页面可作为实现证据，但其 1 万条导出上限只属于当前实例，不能作为其他业务固定上限。

## 业务检查

- 已选、已筛选、全部数据和空数据四种范围正确。
- 确认数量与实际请求范围一致。
- 超限、任务失败和下载失败均有明确反馈。
- 导出不意外修改筛选、分页或业务数据。
