# AES 表格勾选 Feature

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Feature，不作为 Common Design 的通用能力规范。
> `Coverage: extend`
> 本文明确规定的 AES 能力规则优先；未覆盖事项由 `prd-design-code` 按 Coverage 调用 Common Design 补充。

适用于所有带复选框的表格，提供单行勾选和表头全选能力，为批量操作提供数据选择结果。

## Feature 身份与封装

- `featureId: table-selection`
- `encapsulation: false`
- 当前没有映射到 AES 前端业务封装，按本 Feature 契约实现。

## 1. 数量上限与批量操作边界

- 勾选数量上限是可选配置，默认不限制；未开启时支持选中当前筛选条件下的全部数据。
- 开启上限后，页面必须校验勾选数量并在超限时阻断操作。
- 仅在开启勾选上限时，必须满足：**勾选数量上限 > 批量操作数量上限**。
- 本规范只负责数据勾选环节。批量操作独立复用当前勾选结果，并在操作触发时执行独立的二次数量校验；勾选无上限不代表批量操作无上限。
- 两个环节分别触发各自提示，不得用一个上限或一条提示覆盖另一环节。

## 2. 勾选操作

### 2.1 表头全选

#### 未开启勾选数量上限

- 点击全选后，一次性选中当前筛选条件下的全部数据。
- 表头复选框进入全选状态，底部已选计数同步为总条数；不得弹窗阻断。

#### 已开启勾选数量上限

- 数据总量不超过上限时，按普通全选处理。
- 数据总量超过上限时，点击全选立即校验并弹出：`最多勾选 X 条事件，将按顺序选择前 X 条事件数据`。
- 弹窗按钮为「确定」和「取消」：确定后按当前排序选择前 `X` 条，取消后保持勾选前的原始状态。

### 2.2 手动逐行勾选

#### 未开启勾选数量上限

- 点击行首复选框即可自由选中或取消，不限制数量。
- 每次操作实时更新已选计数，并同步表头全选、半选或未选状态；不得弹窗阻断。

#### 已开启勾选数量上限

- 已选数量小于上限时，按普通逐行勾选处理。
- 已选数量达到上限后点击新行时，弹出：`超出已选数量上限（X个），建议从已选列表重新调整勾选数据`。
- 弹窗仅提供「知道了」；本次操作不生效，目标行保持未选中。用户取消已选项后才可继续勾选。

## 3. 状态与计数

### 3.1 表头复选框三态

- 未选：所有行均未选中，表头为空。
- 半选：部分行选中，表头为半选。
- 全选：当前页或当前筛选范围内所有行均选中，表头为实心全选。

### 3.2 已选计数

- 常驻列表底部操作栏，文案为 `已选择 X 项`。
- 每次勾选或取消后实时刷新。
- 开启上限时可追加 `已选择 X / X 项`，并提供清空入口（如页面存在批量操作栏）。

## 4. 边界与异常

1. 筛选条件变化后自动清空原有勾选，避免跨筛选条件累计计数。
2. 分页切换默认保留勾选并跨页累计计数；业务明确要求时才配置为切页清空。
3. 表格刷新后，已选数据若被过滤或删除，自动从已选集合移除并同步计数。
4. 上限动态变更以当前页面最新配置为准；已选数量超过新上限时不强制清退，只阻断新增勾选。

## 5. 业务准出要求

- 表头全选、逐行勾选均覆盖无上限和已开启上限两种模式。
- 表头准确呈现未选、半选和全选三态，计数每次操作实时更新。
- 全选超限和逐行超限使用不同提示与按钮，且均阻断超限动作。
- 筛选、分页、刷新、删除/过滤和动态上限变更符合边界规则。
- 勾选上限与批量操作上限独立校验，并满足严格大于关系（仅两者均开启时）。
- 已选数据、计数和底部操作栏在跨页场景保持一致。
