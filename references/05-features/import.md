# AES 数据导入 Feature

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Feature，不作为 Common Design 的通用能力规范。数据导入在 Coverage 中为 `override`：本文作为当前能力的唯一设计来源，缺失的 AES 导入规则进入 `reference_gaps`，不得自动回退 Common Design。

## 使用边界

本 Feature 在页面方案已确定提供导入能力后读取，完整执行“下载模板 → 上传文件 → 提交导入 → 查看进度 → 查看结果”。Theme 或用户已锁定导入时直接执行；本 Feature 不判断页面是否应该提供导入，也不改变页面主容器。上游不得另建一套导入配置、进度或结果形态覆盖本文。

资产身份信息导入以 MAC 地址匹配资产并更新身份字段，属于独立业务流程，不适用本 Feature。

## 执行流程

```text
列表工具栏“导入”
→ 导入配置：下载模板、上传文件、冲突规则
→ 导入进度：文件名、阶段、进度、已处理数量
→ 导入结果
   ├─ 完全成功：成功图标、数量摘要、关闭
   └─ 含失败或冲突：数量摘要、异常列表、异常报告、完成操作
```

三个阶段互斥；切换阶段时关闭上一主弹窗，不叠加多个主弹窗。

## 配置与提交

- 导入作为列表工具栏全局操作，不依赖表格勾选。
- 按“下载模板 → 上传文件 → 设置冲突规则 → 提交导入”组织。
- 上传前校验格式、空文件和大小；没有有效文件时禁用“导入”。
- 只有不同冲突策略会产生不同结果时才展示策略控件；否则持续说明固定处理方式。
- 业务字段校验结果必须展示服务端返回的行号、字段、内容和原因。

## 进行中状态

- 区分文件上传和导入任务，分别反馈进度。
- 提交成功后进入独立进度状态，不允许返回修改文件或策略。
- 防止重复提交、重复轮询；文件过期时清理旧状态并要求重新上传。
- 没有任务中心、通知等恢复入口时，不允许任务被无反馈关闭或丢失；有恢复入口时说明任务仍在执行及找回方式。

## 结果与异常

- 完全成功仅展示成功结果和关闭入口，不展示异常列表或报告。
- 失败数或冲突数大于 0 时统一使用异常结果，不为部分失败、全部失败等另造页面。
- 异常结果展示成功、失败、跳过/冲突数量，以及行号、类型、异常字段、导入内容、异常描述五列。
- 有有效报告文件时展示“下载异常报告”，否则不显示无效入口。
- 完成后刷新列表，清理旧选择、文件、策略、进度和结果；页面卸载时停止轮询。

## AES 参考基线

- 自定义 IOC / 文件 Hash：`/aes/policy/ioc-policy/hash`
- 同类页面：`/aes/policy/ioc-policy/ip`、`/aes/policy/ioc-policy/domain`
- 当前参考实例使用 CSV、20 MB 上限和“跳过/替换”；这些值只作为该实例证据，其他业务必须以当前需求和配置为准。

## 业务检查

- 配置、进度、结果三个阶段按顺序切换且不重叠。
- 覆盖上传失败、文件过期、任务失败、完全成功和含失败/冲突结果。
- 异常明细、报告下载、列表刷新和状态清理均可执行。
