# AES 文件大小显示 Feature

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Feature，不作为 Common Design 的通用能力规范。本文明确规定的 AES 能力规则优先；未覆盖事项由 `prd-design-code` 按 Coverage 调用 Common Design 补充。

## 1. 调用场景

当列表、详情、卡片、提示信息或生成代码中需要展示文件大小时，调用本规则。

输入为非负整数字节数，输出格式为：

`数值 + 1个半角空格 + 单位`

示例：`512 B`、`18.3 MB`

## 2. 换算规则

采用二进制 `1024` 进制：

- `1 KB = 1024 B`
- `1 MB = 1024² B`
- `1 GB = 1024³ B`

根据原始字节数选择单位：

| 原始大小 | 单位 |
| :--- | :--- |
| `< 1024 B` | `B` |
| `≥ 1024 B 且 < 1 MB` | `KB` |
| `≥ 1 MB 且 < 1 GB` | `MB` |
| `≥ 1 GB` | `GB` |

先根据原始字节数选择单位，再换算和四舍五入，不因舍入结果切换单位。

## 3. 精度规则

- `B`、`KB`：四舍五入为整数。
- `MB < 10`：固定保留 1 位小数，如 `5.0 MB`。
- `MB ≥ 10`：最多保留 1 位小数，末尾为 `.0` 时省略，如 `18.3 MB`、`128 MB`。
- `GB`：固定保留 1 位小数，如 `1.0 GB`、`1.2 GB`。

单位固定使用 `B`、`KB`、`MB`、`GB`，数值与单位之间保留一个半角空格。

## 4. 异常值

- `0` 展示为 `0 B`。
- 空值、非数字、负数等无效输入展示为 `-`。
- 不自动扩展到 `TB`，大于等于 `1 GB` 的数据继续使用 `GB`。

## 5. 示例

| 原始字节数 | 最终输出 |
| ---: | :--- |
| `512` | `512 B` |
| `262144` | `256 KB` |
| `2411725` | `2.3 MB` |
| `19188941` | `18.3 MB` |
| `134217728` | `128 MB` |
| `1073741824` | `1.0 GB` |
| `1288490189` | `1.2 GB` |

## 6. 业务要求

- 使用 `1024` 进制。
- 单位根据原始字节数选择。
- 精度和末尾 `.0` 符合对应单位规则。
- 数值与单位之间有一个半角空格。
- 无效输入不展示为 `0 B`。
