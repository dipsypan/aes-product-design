# AES 资产范围 Feature

> **归属：AES Product Design。** 本 Reference 是 AES（深信服下一代端点安全）产线专属 Feature，不作为 Common Design 的通用能力规范。本文明确规定的 AES 能力规则优先；未覆盖事项由 `prd-design-code` 按 Coverage 调用 Common Design 补充。

## 1. 调用条件

当策略、任务、白名单或其他业务需要配置资产生效对象时，调用本规则。

Theme 或用户已经锁定使用本 Feature 时直接完整执行，不得重新判断是否需要资产范围能力。对于规则管理，只要用户确认不是固定对全部资产生效，就必须调用本 Feature。

类似 IOC 的全局生效对象，或资产范围固定且不可修改的对象，不调用本规则。

## 2. 统一术语

| 语义 | 页面文案 |
| :--- | :--- |
| 策略、白名单的配置分区 | 适用对象 |
| 策略、白名单的资产选择 | 适用资产 |
| 任务的配置分区 | 执行对象 |
| 任务的资产选择 | 执行资产 |
| 用户分配的资产或资产组 | 分配资产 |
| 排除的资产或资产组 | 排除资产 |
| 计算后的最终资产 | 生效资产 |

“资产范围”仅作为本规则的内部概念，不作为默认页面标题或字段文案。

## 3. 表单配置

### 3.1 策略和白名单

```text
适用对象

适用资产：   ( ) 全部资产   ( ) 指定资产
指定资产：   [资产选择器]
排除资产：   [资产选择器]
```

### 3.2 任务

```text
执行对象

执行资产：   ( ) 全部资产   ( ) 指定资产
指定资产：   [资产选择器]
排除资产：   [资产选择器]
```

规则：

- 先选择“全部资产”或“指定资产”。
- 选择“指定资产”后，显示“指定资产”选择框，并至少选择一个资产或资产组。
- 无论选择“全部资产”还是“指定资产”，都显示“排除资产”选择框。
- “排除资产”允许为空，支持选择资产和资产组。
- 如果业务存在“暂不分配”，必须作为独立业务状态处理，不得当作“全部资产”或“指定资产”。

## 4. 资产选择器组件

资产选择器组件的调用方式和组件能力见 [`../06-components/asset-selector.md`](../06-components/asset-selector.md)。本 Feature 只规定资产选择能力的执行流程、范围关系和业务语义。

## 5. 生效资产计算

无优先级业务：

```text
生效资产 = 分配资产 - 排除资产
```

全部资产场景：

```text
生效资产 = 全部资产 - 排除资产
```

存在策略优先级时：

```text
生效资产 = 根据优先级处理后的分配资产 - 排除资产
```

生效资产数量和详情不能只根据分配资产计算，必须考虑排除资产；有优先级时还必须考虑优先级。

生效资产表头必须带小 `i` 提示：

- 无优先级：`生效资产是指分配资产减去排除资产后，实际生效的资产。`
- 有优先级：`生效资产是指在分配资产和排除资产基础上，进一步考虑优先级后，实际生效的资产。`

## 6. 列表展示

存在资产配置时，列表必须同时表达三种业务语义：

```text
分配资产 | 排除资产 | 生效资产
```

规则：

- 分配资产列显示“全部资产”或指定资产/资产组。
- 排除资产列无数据时显示 `-`。
- 生效资产列显示最终生效资产或数量，并带小 `i` 提示。
- 资产较多时显示数量和代表性名称，不因省略而丢失完整查看入口。
- 三列内容均支持点击查看完整资产。
- “分配资产、排除资产、生效资产”是不可省略、不可合并的三种字段语义；用户可以根据当前业务术语微调展示名称，但调整后仍需清晰区分三者，且列表、详情和抽屉保持一致。

## 7. 点击与抽屉

点击分配资产、排除资产或生效资产列时，打开 AES 封装的资产详情抽屉（如 `PolicyAssetsDrawer` 或同等业务封装）。

抽屉按标签页展示：

```text
分配资产 | 排除资产 | 生效资产
```

规则：

- 默认打开与用户点击列对应的标签页。
- 展示资产名称、资产类型、IP、资产组等完整信息。
- 生效资产标签页展示经过排除资产和优先级计算后的结果。
- 无对应数据时展示空状态，不打开无意义的空列表。
- 长名称和路径遵循 AES 的省略及 Tooltip 规则。
- 不在业务页面重复实现资产详情抽屉。

## 8. 详情展示

详情页至少应能区分以下信息：

```text
适用资产/执行资产：全部资产或指定资产
排除资产：...
生效资产：...
```

已有独立资产配置分区时，不重复增加相同字段，但必须能清楚表达分配、排除和生效关系。

## 9. 业务要求

- 非全局固定对象支持全部资产/指定资产选择。
- 指定资产时显示资产选择器并完成必填校验。
- 全部资产和指定资产两种情况下均显示排除资产选择器。
- 使用 AES 资产选择能力，未混用不符合业务范围的通用选择方式。
- 列表固定保留分配、排除、生效三种资产字段语义；展示名称允许用户按业务语境微调。
- 生效资产正确扣除排除资产，并在有优先级时叠加优先级计算。
- 生效资产表头带小 `i` 提示。
- 三个资产列均可点击打开资产详情抽屉。
- 抽屉支持查看分配、排除和生效资产。
- 同一页面不混用“适用对象”“适用资产”“执行对象”“执行资产”以外的旧表述。
